## 구성

```
index.html          요약표 (정렬·클릭 이동)
u/<대학>.html        대학별 세부 페이지 + 참고문헌
assets/style.css    스타일 (라이트/다크)
assets/app.js       정렬·다크모드·행 이동
data/universities.json  데이터 원본
```

빌드 도구 없이 정적 HTML/CSS/JS로만 동작합니다. `index.html`을 브라우저로 열면 됩니다.
